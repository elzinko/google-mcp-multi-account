Cartes profil — v3

Trois changements depuis la v2 : les alias (gwsa perso…) disparaissent de l'aperçu — l'email suffit ; « accès sur demande » est reformulé en clair ; les boutons destructeurs ont un encadré. Clique une carte pour la déplier, un email pour le copier.

Ce qui change dans la v3
  • Plus d'alias dans l'aperçu. Le titre, c'est l'email. L'alias reste la clé technique côté serveur (visible via gwsa list / journaux) mais n'encombre plus la carte.
  • « Verrouillé » expliqué. Fini « accès sur demande » : la carte dit « un LLM doit te demander l'accès ».
  • Boutons destructeurs encadrés. « Retirer », « Révoquer » ont un contour dès le repos — ça se lit comme un bouton, plus comme du texte.
