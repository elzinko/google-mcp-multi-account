google-multi-accountMulti-account Google Workspace for agents

Plusieurs comptes Google. Un agent. Toi aux commandes.

Serveur MCP local (bin/google-mcp) pour brancher Claude, Cursor et consorts sur Gmail, Drive, Calendar, Docs, Sheets et Tasks — sans cloud tiers, avec verrous et policy.

Installer Lire la doc

Le problème

Un agent avec tes mails, sans garde-fou, ce n’est pas un outil.

Les MCP Google classiques ouvrent un compte, souvent trop large. Ici le produit part d’une contrainte : l’agent peut demander, jamais s’élargir tout seul.

Multi-comptes, pas un seul token

Perso, asso, client : chaque profil a sa policy, ses verrous, ses zones Drive. L’agent cible un alias, pas « ton Google » en bloc.

100 % local

Rien ne tourne dans un SaaS intermédiaire. Le seul passage Google Cloud, c’est la création one-shot de l’identifiant OAuth.

Comment ça marche

L’humain ouvre. L’agent exécute dans le cadre.

MCP stdio pour le LLM, CLI gwsa et admin locale pour toi. Chaque porte — unlock, grant, nouveau compte — reste un geste humain.

  1. Brancher le serveur MCP

    Claude Desktop / Claude Code / Cursor parlent à bin/google-mcp. Les tools découvrent les profils et demandent l’accès proprement.

  2. Élicitation, pas exécution

    Profil verrouillé ou zone Drive manquante ? L’agent propose la commande exacte. Toi (Touch ID optionnel) tu la lances.

  3. Policy default-deny

    Service non déclaré = refus. Écriture Drive limitée aux dossiers accordés. Les tools Gmail s’arrêtent au brouillon.

Sécurité

Ne pas faire confiance au LLM par défaut.

Le parti pris produit : chaque élargissement d’accès passe par toi. Le détail honnête — y compris les limites — est dans le threat model.

Verrous
Profil verrouillé = aucun accès aux données, MCP compris, jusqu’à un unlock humain.
Default-deny
Policy par service et par profil. Nouveau compte = policy prudente.
Zones Drive
Écriture uniquement sous dossiers autorisés ; grants temporaires qui expirent.
Touch ID
Strongauth optionnel pour unlock, grant et ajout de compte.
Local first
Tokens chiffrés, clé dans le Trousseau macOS, journal d’audit par client.

Lire SECURITY.md et le modèle de menace.

Quickstart

Trois gestes pour démarrer.

macOS Apple Silicon aujourd’hui. Le détail et les autres clients sont dans la documentation. 

git clone https://github.com/elzinko/google-mcp-multi-account.git
cd google-mcp-multi-account
brew install googleworkspace-cli
ln -sf "$PWD/bin/gwsa" "$(brew --prefix)/bin/gwsa"
./scripts/provision-gcp.sh
./scripts/update.sh

Puis redémarre Claude Desktop (Cmd-Q) et demande : « fais le point sur mon setup Google ». Guide complet : README · hub documentation.
