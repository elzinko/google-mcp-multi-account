🗂️ gws multi-comptes — admin

Profils = comptes Google connectés localement (tokens chiffrés dans ~/.config/gws-accounts/<alias>/). Un profil 🔒 refuse toute commande tant que tu ne l'as pas déverrouillé — l'« accès sur demande » que les LLM doivent te demander. La policy limite ce que chaque profil peut faire ; pour Drive, l'écriture se fait par zones : permanentes (policy) ou temporaires (élicitation, gwsa grant).

Connecter un compte Google

Un onglet Google s'ouvre : choisis bien ce compte-là (présélectionné), écran « app non validée » → Paramètres avancés → Accéder, puis accepte. Mauvais compte = refus automatique.

Déverrouiller

Fenêtre temporaire (reverrouillage automatique) ou retrait du verrou.

⛔ Révoquer

Les tokens sont supprimés de ce Mac : tous les LLM perdent immédiatement l'accès à ce compte. (Révocable aussi côté Google : myaccount.google.com → Sécurité.)
