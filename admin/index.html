🗂️ gws multi-comptes — admin

La ligne d'un compte se lit en deux temps. Le cadenas : l'accès est-il verrouillé ou déverrouillé ? C'est un bouton — clique dessus. Le décompte : le temps restant, en vrai. Un compte déconnecté est grisé : « Reconnecter » sur la ligne, ou « + Connecter un compte ».

Connecter un compte Google

Un onglet Google s'ouvre : choisis bien ce compte-là (présélectionné), écran « app non validée » → Paramètres avancés → Accéder, puis accepte. Mauvais compte = refus automatique.

Verrouiller l'accès ?

Les assistants ne pourront plus accéder à ce compte jusqu'au prochain déverrouillage.

Déverrouiller

Fenêtre temporaire (verrouillage automatique) ou retrait du verrou.

⛔ Révoquer

Les tokens sont supprimés de ce Mac : tous les LLM perdent immédiatement l'accès à ce compte. (Révocable aussi côté Google : myaccount.google.com → Sécurité.)
